3D Spatial Reasoning Puzzle

        
Connect every node and complete the network. Each node shows how many connections it needs.

      

    

    

      

        
Nodoku is a 3D connection puzzle. Link neighbouring nodes until every dot is cleared and every node belongs to one network.


        

          
How to Play Nodoku

          
Each dot is one connection that node still needs. A connection clears one dot from both nodes. Solve the puzzle when every dot is gone and the whole network is connected.

        


        

          
Why Nodoku Is 3D

          
Rotate the puzzle to reveal neighbouring nodes hidden by the current view. The rules stay the same from every angle.

        


        

          
Frequently Asked Questions

          
What do the dots mean?

          
Each dot is one connection that node still needs.

          
How do you solve Nodoku?

          
Clear every dot and make sure all nodes belong to one connected network.

          
Why is Nodoku 3D?

          
Rotate the puzzle to reveal neighbours that are hidden from the current view.
