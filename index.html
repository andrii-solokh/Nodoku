3D Spatial Reasoning Puzzle

Connect every node and complete the network. Each node shows how many connections it needs.

Nodoku is a 3D spatial reasoning puzzle built around nodes and connections. Each node has between one and four dots showing exactly how many connections it requires. Connect every node so all connection requirements are satisfied and the entire network forms one valid connected structure.

How to Play Nodoku

Every node in Nodoku contains between one and four dots. The dots represent the exact number of connections that node must have when the puzzle is complete. Connect neighboring nodes until every requirement is satisfied, while keeping the entire structure in one connected network. A completed node has no dots left to use. If a node still has dots, it still needs links.

Start by looking for clear constraints: a node with one dot has a single connection to make, while a node with several dots needs more room around it. Each connection affects both of its endpoints, so every move reveals a little more about the rest of the network.

A Puzzle About Logic and Spatial Reasoning

The dots in Nodoku are not values to calculate. They are connection constraints. Every connection changes what is possible for nearby nodes, so the puzzle rewards planning, deduction, and checking the connectivity of the whole graph. A locally valid connection can still leave a separate group behind, which is why the final network must be joined together.

That balance makes Nodoku a spatial logic puzzle: use each small clue, consider the remaining choices around it, and keep an eye on the shape that is forming across the board.

Why Nodoku Is 3D

Unlike a flat node puzzle, Nodoku places nodes in three-dimensional space. Rotate the structure to inspect hidden relationships and see which nodes are neighbors on another face. The perspective changes, but the constraints do not. Looking at the network from more than one angle is part of solving the 3D puzzle, not just a visual effect.

That makes each board a compact spatial puzzle and a 3D brain puzzle: the connections form a network you can explore from every side.

Frequently Asked Questions

What is Nodoku?

Nodoku is a 3D spatial reasoning puzzle where players connect nodes while satisfying the required number of connections shown on each node.

What do the dots mean?

The number of dots on a node tells you exactly how many connections that node must have in the completed puzzle.

How do you solve Nodoku?

Connect nodes until every node has the correct number of connections and all nodes belong to one connected network.

Is Nodoku a number puzzle?

Nodoku uses numbers as connection constraints, but the game is primarily a logic, network, and spatial reasoning puzzle rather than an arithmetic puzzle.

Why is Nodoku 3D?

The nodes exist in three-dimensional space, so players must rotate the puzzle and reason about relationships that may not be visible from a single viewpoint.
