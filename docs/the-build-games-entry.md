Before submitting:

- Verify the production deployment includes the merged changes and that all three URLs load and start a puzzle.
- Make the GitHub repository public. It is private as of this draft; changing visibility publishes the repository's entire history, so review that history first.
- Supply the entrant's real name and email, review [the rules](https://canivibecodeit.com/thebuildgames/terms), and personally accept the terms on the form.
- Be precise about the build window: the repository began in February 2026, while the current TypeScript web game and character editions have September commits. The organizers decide whether this meets their requirement that judged work was done during the September window.

This is preparation for an entry, not confirmation that one was submitted.
